# Repository description

**Short description for GitHub's About field**

A 100-floor offline-first Android idle tower-defense game in stylized 2D dark fantasy. Play as the Demon Lord, defend your Demonic Core, evolve guardians, defeat invading heroes and bosses, research permanent upgrades, and unlock endless prestige.

**Extended description**

Core Guardian: Demon Lord's Tower is an original dark-fantasy idle tower-defense game for Android. Heroes climb a 100-floor tower to steal the Demon Lord's treasure and kill its ruler. The player builds and evolves automatic defenses, commands original demon guardians, chooses upgrades and abilities, researches permanent improvements, earns bounded offline rewards, and faces milestone bosses. Heroes must destroy the Demonic Core before reaching the throne. The initial release is fully offline, with local versioned saves, a ten-region campaign, endless survival, and prestige.

**Status:** Design and roadmap committed; game implementation and APK verification are not yet claimed.
